# B2B-Machinery-retail-CRM

Lightweight B2B CRM web application built with Python, Streamlit, and SQLite for managing heavy machinery sales, inventory, and customer pipelines.

## Local Setup
1. Clone the repository:
   `git clone https://github.com/KINGKRON3/B2B-Machinery-retail-CRM.git`
2. Navigate to the folder:
   `cd B2B-Machinery-retail-CRM`
3. Install dependencies:
   `pip install -r requirements.txt`
4. Run the application:
   `python -m streamlit run app.py`
